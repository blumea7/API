## HTTPS Port 443
- Among the 65k ports that direct traffic, it's the only one that handles the **HTTPS**


## What is a port
- It's like a door with a number on a computer/server
- When **data comes in** from the **internet** it must go through a door (port)

## What is HTTPS
- HTTP = HyperText Transfer Protocol = how web browsers and web servers talk
- HTTPS = HTTP Secure = same thing, but encrypted so others can't tamper it
- HTTPS uses TLS (Transport Layer Security) / SSL encryption to protect data

## What is Port 443
- Default port for HTTPS
- When you go to https://any.com, your browser automatically try to connect to that server on port 443, unless told otherwise
- If port 443 is blocked, secure websites or APIs won't usually load
